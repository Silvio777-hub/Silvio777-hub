## Research Interests & Thesis Work

My academic and engineering work operates at the intersection of **Formal Software Engineering** and **Generative Machine Learning**:

* **Grammar-Constrained Program Synthesis:** Developing multi-agent pipelines (`Agentic-HTML5-Parser`) that integrate abstract syntax tree (AST) schema validation with iterative self-healing loops to eliminate syntactic hallucinations in generative code models.
* **High-Assurance & Zero-Trust Systems:** Engineering cryptographic platforms implementing AES-256-GCM encryption-at-rest, side-channel-resistant constant-time authentication, and local-first data custody.
* **Distributed Systems & Queueing Theory:** Quantitative performance modeling using Open Queueing Networks (QN) and Layered Queueing Networks (LQN) to predict scaling bottlenecks in cloud-native microservices.
