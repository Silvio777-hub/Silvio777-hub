## I. Research Focus & Master's Thesis

My research and engineering operate at the intersection of **Formal Software Verification** and **Generative Machine Learning**:

* **Grammar-Constrained Program Synthesis:** Developing multi-agent pipelines (`Agentic-HTML5-Parser`) that integrate abstract syntax tree (AST) schema validation with iterative self-healing loops to eliminate syntactic hallucinations in generative code models.  
  [![Domain](https://img.shields.io/badge/Domain-Neurosymbolic_AI-0052CC?style=flat-square)]()
  [![Method](https://img.shields.io/badge/Method-AST_Schema_Validation-2E4053?style=flat-square)]()
  [![Architecture](https://img.shields.io/badge/Architecture-Multi--Agent_Systems-5B2C6F?style=flat-square)]()

* **High-Assurance & Zero-Trust Systems:** Engineering cryptographic platforms implementing AES-256-GCM encryption-at-rest, side-channel-resistant constant-time authentication, and local-first data custody.  
  [![Security](https://img.shields.io/badge/Security-Zero--Trust_Architecture-922B21?style=flat-square)]()
  [![Cryptography](https://img.shields.io/badge/Cryptography-AES--256--GCM-B9770E?style=flat-square)]()
  [![Hardening](https://img.shields.io/badge/Hardening-Constant--Time_Auth-117A65?style=flat-square)]()

* **Distributed Systems & Queueing Theory:** Quantitative performance modeling using Open Queueing Networks (QN) and Layered Queueing Networks (LQN) to predict scaling bottlenecks in cloud-native microservices.  
  [![Theory](https://img.shields.io/badge/Theory-Queueing_Networks_(QN)-6C3483?style=flat-square)]()
  [![Analysis](https://img.shields.io/badge/Analysis-Layered_Queueing_(LQN)-1B4F72?style=flat-square)]()
  [![Scale](https://img.shields.io/badge/Scale-M%2FM%2Fc_Capacity_Planning-145A32?style=flat-square)]()
